# JanSwar research prototype

Browser-only demonstration of health-demand aggregation concepts using built-in sample data. It does not record audio, collect or transmit form submissions, integrate with government systems, or use an AI API.

## Run locally

Requires Node.js 24 or later.

1. `npm install`
2. `npm run dev`
3. `npm run lint`
4. `npm run build`

`npm run clean` removes only the generated `dist` folder.

Before any public launch, replace the sample records and unverified catalog/location/pricing data; implement a reviewed backend; and have the legal notices reviewed for the actual business and visitor jurisdictions.
